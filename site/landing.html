Build on Foundry.
Set up in one command.

Microsoft Foundry is the platform for building, testing, and deploying AI apps and agents. Foundry DevPack installs the developer tools that connect that lifecycle across your editor, terminal, and coding agent.

powershell -ex AllSigned -c "Invoke-RestMethod 'https://aka.ms/foundry-devpack-install.ps1' | Invoke-Expression"

Everything DevPack installs

Foundry Toolkit Build, test, evaluate, and deploy from Visual Studio Code.

azd + azd ai Scaffold, deploy, evaluate, and automate from the terminal.
↗
Foundry Canvas Preview Design and deploy hosted agents with a guided Copilot canvas.
