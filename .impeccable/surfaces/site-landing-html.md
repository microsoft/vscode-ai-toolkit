## Scope and mode

- Route: `/` from `site/landing.html`
- Mode: Persuade

## Audience and job

Developers evaluating or starting on Microsoft Foundry need to understand how the platform and local developer tools fit together, then install those tools without assembling the environment manually.

## Primary action and proof

- Primary action: select Windows or macOS/Linux and copy the exact DevPack install command.
- Proof: one plain linked summary shows the four developer surfaces installed by the DevPack command.
- Supporting content: concise descriptions and first-party documentation links inside that summary.

## Constraints

- The existing changelog remains intact at `/changelog/`.
- The landing page uses Microsoft Foundry's precise type and restrained purple actions, restores a subtle grid field per user feedback, and supports persistent light and dark themes without restoring the gradient frame or product marks.
- The changelog keeps its existing VS Code release-notes visual language and behavior.
- Installation commands remain usable without JavaScript and copy behavior surfaces failure.
- Foundry Canvas is labeled Preview.

## Direction and memorable moment

Use one concise hero and no follow-on content section. The sole installer sits beside one plain linked tool summary that combines the former setup window and tool cards. Keep both product marks, the gradient frame, separate tool band, platform lifecycle, repeated installer, and duplicate descriptions removed. Use a subtle grid field and a compact light/dark theme control.
